# 复试高频面试题清单

> 使用方法：从阶段 1 开始，学完对应内容就把自己的答案写在题目下面（一两句话即可）。
> 复试冲刺期（2028.01 起）逐题过一遍，做到脱口而出。
> ⭐ = 出现频率极高，⭐⭐ = 本项目必被问。

## 一、深度学习基础

- ⭐ 什么是梯度下降？学习率过大/过小会怎样？
- ⭐ 反向传播在做什么？
- ⭐ 过拟合怎么判断？有哪些缓解方法？（Dropout、正则化、早停、数据增强）
- ⭐ 激活函数的作用？ReLU 为什么常用？（梯度消失角度）
- 批归一化（BatchNorm）和层归一化（LayerNorm）的区别？为什么 Transformer 用 LayerNorm？

## 二、Transformer 与大模型原理

- ⭐⭐ Self-Attention 的公式和直觉？Q/K/V 分别是什么？为什么要除以 √d_k？
- ⭐⭐ Multi-Head Attention 的意义？（不同子空间捕获不同模式）
- ⭐ Transformer 位置编码为什么需要？正弦位置编码 / RoPE 了解吗？
- ⭐⭐ BERT 和 GPT 的区别？（双向理解 vs 自回归生成；Masked LM vs Next Token Prediction）
- ⭐⭐ 大模型训练三阶段：预训练 → SFT → RLHF，各自做什么？
- 为什么 RNN 处理长序列有困难，Transformer 解决了什么？（并行性 + 长程依赖）
- Token、词表（vocab）、温度系数（temperature）、top-p 采样分别是什么？
- 模型的参数量和显存占用怎么估算？（fp16 下参数量 × 2 字节 + 激活值）

## 三、RAG（本项目核心，必被问）

- ⭐⭐ RAG 的完整流程？相比直接问大模型的优势？
- ⭐⭐ 文本分块（chunking）策略有哪些？chunk_size 和 overlap 怎么定？你是怎么实验的？
- ⭐ Embedding 是什么？为什么语义相近的文本向量距离近？
- ⭐⭐ 向量数据库的 ANN（近似最近邻）检索原理？HNSW / IVF 了解吗？为什么不用暴力检索？
- ⭐ 为什么要加 rerank（重排）？粗排和精排的区别？
- ⭐⭐ 混合检索（BM25 + 向量）为什么效果更好？（关键词精确匹配 + 语义泛化）
- ⭐⭐ 大模型幻觉是什么？你的项目里怎么缓解？（引用溯源 / 反思机制 / 忠实度评估）
- ⭐⭐ RAG 和微调怎么选？（知识时效性/可更新 vs 风格与格式内化；你项目里两者结合）
- 检索回来的内容答非所问怎么办？（query 改写、反思重检索——Agentic RAG）
- 多轮对话中"它呢？"这种指代怎么处理？（对话历史改写查询）

## 四、Agent

- ⭐⭐ Function Calling / 工具调用的原理？（模型输出结构化调用意图，代码执行后回填）
- ⭐ Agent 的基本构成：规划（Planning）+ 记忆（Memory）+ 工具（Tools）+ 执行（Action）
- ⭐ LangGraph 和普通 LangChain 链的区别？（状态图、条件边、循环 vs 单向流水线）
- ReAct 模式是什么？（Reason + Trace 交替）
- MCP 协议是什么？（模型连接外部工具/数据的标准协议，2025 起的行业热点）
- 多智能体协作适合什么场景？（分工 + 辩论 + 审核）

## 五、微调

- ⭐⭐ LoRA 的原理？为什么省显存？（冻结 W，只训低秩分解 ΔW=BA，r≪d）
- ⭐ LoRA 的 rank（r）一般取多少？过大过小的影响？
- QLoRA 和 LoRA 的区别？（4bit 量化基座 + LoRA）
- 全量微调 vs LoRA vs Prompt-tuning 的对比？
- 你的微调数据集怎么构造的？多少条？怎么清洗？
- 微调后怎么验证有效？（同一评估集跑分对比——呼应你的评估报告）

## 六、工程与部署

- ⭐ FastAPI 为什么适合做模型服务？（异步、自动文档、类型校验）
- Docker 解决了什么问题？（环境一致性）
- 流式输出（SSE）怎么实现的？为什么体验更好？
- 如果并发用户多了，你的系统会先卡在哪里？怎么扩展？（GPU 推理吞吐 → vLLM / 请求队列）

## 七、项目开放题（最考验真实性）

- ⭐⭐ 你在项目里遇到的最大困难是什么？怎么解决的？（提前准备 2 个真实踩坑故事）
- ⭐⭐ 你的系统评估指标是多少？怎么测的？还有什么不足？
- 如果让你把这个项目做到生产级，你还需要做什么？（鉴权、日志监控、压测、成本控制）
- 为什么选这个领域/题目？
- 这个项目后续可以怎么扩展？（多模态文档、GraphRAG、端侧部署）

## 八、反问环节（复试结尾可以问导师的）

- 实验室目前在大模型方向主要研究哪些问题？
- 研究生阶段如果参与实验室项目，需要提前补充哪些知识？
