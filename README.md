## 使用方法

1. 每周打开当前阶段的 notes 文件，按任务清单推进，完成后打勾；
2. 学习中产生的笔记直接写在对应 notes 文件里（或单独建文件，从 notes 里链接过去）；
3. 每个阶段的"自测题"能脱口而出，才算过关；
4. 面试题清单从阶段 1 起就可以开始填答案，复试前会感谢现在的自己。
