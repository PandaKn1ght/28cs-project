		    创建版本库：git add+git commit，commit记得要加-m"xxx"
		    回到不同版本：code xxx召唤vscode，git status能查看每次改动的状态，git diff告诉你每次改动的不同，git log观察修改日志
					      git reset --hard HEAD^可以回到HEAD的上一个版本，--hard会回退到上个版本的已提交状态，而--soft会回退到上个版本的未提交状态，--mixed会回退到上个版本已添加但未提交的状态。hard后面也可以加版本号（commit后面的一长串的前几位）回到最新版本。
		    工作区、暂存区（stage）和master：后二者合称为版本库，add是先加入stage，commit才全部移入master。对应可以理解--hard/--mixed/--soft分别回到的是哪里。
		        git restore <file>             # 后悔 1：改了没 add，想扔掉修改
			git restore --staged <file>    # 后悔 2：add 了还没 commit，想退出暂存区（改动保留）
			git reset --hard HEAD^         # 后悔 3：commit 了，想整个回退到上一个版本（危险，会丢改动）
			git checkout -- readme.txt的命令可以替代restore --staged，checkout本质是吧版本库粘贴到工作区。
		     删除文件：rm+commit提交
远程仓库：
