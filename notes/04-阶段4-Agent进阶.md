# 阶段 4：Agent 进阶 → v2.0（第 17-22 周，约 60h）★差异化关键

**目标**：从"固定流水线 RAG"升级为"Agent 自主编排"，并建立量化评估体系——这是你和其他"烂大街 RAG 项目"拉开差距的地方。

## 任务清单

### 第 17 周：Function Calling
- [ ] 原理：模型输出结构化工具调用意图（JSON），代码执行后把结果回填对话
- [ ] 实现三个工具：知识库查询 / 计算器 / 获取当前时间
- [ ] 工具描述（description）怎么写才能让模型选对工具？做对比实验

### 第 18 周：LangGraph 入门
- [ ] 核心概念：State（状态）、Node（节点）、Edge（边）、Conditional Edge（条件边）
- [ ] 官方教程跑通一个最小图
- [ ] 实现意图路由节点：闲聊 → 直接回答 / 知识问答 → RAG 分支 / 计算 → 工具分支

### 第 19 周：Agentic RAG
- [ ] 查询改写节点：口语化问题 → 检索友好问题（含指代消解）
- [ ] 检索质量反思节点：判断"检索到的资料能否回答问题"（CRAG 思想）
- [ ] 不合格 → 改写重检索（循环上限 2 次）→ 仍不行 → 诚实告知并给建议
- [ ] 画出你的完整状态图（这张图复试必用）

### 第 20 周：记忆与前沿
- [ ] 多轮对话记忆：对话历史 + 查询改写解决指代
- [ ] 了解 MCP 协议：是什么、解决什么问题（工具接入标准化）、和 Function Calling 的关系
- [ ] 了解多智能体思想：规划者/执行者/审查者分工（不必实现，能讲清楚即可）

### 第 21 周：评估体系 ★最大加分项
- [ ] 自建评测集：50-100 个问题（含答案出处文档），覆盖简单/复杂/闲聊/超纲
- [ ] Ragas 框架：faithfulness（忠实度）、answer_relevancy（答案相关性）、context_precision（检索精度）
- [ ] 跑出基础 RAG 的基线分数

### 第 22 周：对比实验 + v2.0
- [ ] 消融实验：±重排、±查询改写、±反思循环，各配置跑分
- [ ] 写《评估实验报告》（含表格和结论），放进仓库
- [ ] tag v2.0 + 博客：如何用数据驱动 RAG 优化
