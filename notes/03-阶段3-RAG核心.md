# 阶段 3：RAG 核心 → 项目 v1.0（第 11-16 周，约 60h）★核心阶段

**目标**：独立搭通 RAG 全链路，做出第一个可演示的系统版本。

## 任务清单

### 第 11 周：原理 + 语料准备
- [ ] RAG 原理总览：为什么需要（知识时效/私有数据/幻觉/可溯源）
- [ ] 文档解析：PyPDF / pdfplumber 解析 PDF，MarkdownLoader
- [ ] **确定项目领域**（建议：考研 408 知识库 / 高数问答 / 学术文献助手），收集 50-200 份文档
- [ ] 参考 Langchain-Chatchat 和 awesome-llm-apps 的 RAG 示例（学思路，不抄代码）

### 第 12 周：分块 + 向量化
- [ ] 分块策略：固定长度 / 递归字符 / 按标题层级；chunk_size、overlap 概念
- [ ] BGE embedding 模型下载与调用（bge-m3 或 bge-large-zh）
- [ ] FAISS 入门：建库、持久化、相似度检索 top-k
- [ ] 用 10 个测试问题人工检查检索质量，记录问题

### 第 13 周：生成链路
- [ ] Prompt 模板：系统约束（只根据资料回答）+ 检索片段 + 引用标注 [1][2]
- [ ] 接入 LLM（API 或本地），生成带来源的答案
- [ ] 无相关资料时的拒答策略（防幻觉的第一道防线）

### 第 14 周：Gradio 界面
- [ ] 对话窗口 + 历史记录
- [ ] 文档上传入口（增量入库）
- [ ] 答案下方展示引用来源（文档名+页码/片段）

### 第 15 周：检索进阶
- [ ] BM25 原理；BM25 + 向量的混合检索（RRF 融合）
- [ ] bge-reranker 重排接入
- [ ] 消融实验：不加/加重排，人工对比 10 个问题的检索结果

### 第 16 周：v1.0 整理发布
- [ ] README：项目简介、架构图（draw.io 画）、快速开始、效果截图
- [ ] requirements.txt + 代码结构整理 + 注释
- [ ] 打 tag v1.0，写发布博客
