# 阶段 0：环境与工具基础（第 1-2 周，约 20h）

**目标**：搭建好整个学习期和项目期要用的工具链，Git/GitHub 用起来、Docker 不再陌生。

## 任务清单

### 第 1 周
- [ ] 安装 Anaconda（或 Miniconda）+ 创建 Python 3.10 虚拟环境
- [ ] 安装 VS Code + Python 插件
- [ ] 安装 Git，配置 user.name / user.email，生成 SSH key 添加到 GitHub
- [ ] 学完 Git 基础：init / add / commit / log / branch / merge / push / pull
- [ ] 注册 GitHub，创建本工作区对应仓库并首次推送
- [ ] 安装 WSL2（Ubuntu），练习常用命令：cd/ls/mkdir/rm/cat/grep/ps/kill/chmod/curl

### 第 2 周
- [ ] Conda 环境管理：create / activate / list / install / 导出 environment.yml
- [ ] pip 换国内镜像源（清华/阿里）
- [ ] Docker Desktop 安装（Windows 需开启 WSL2 后端）
- [ ] 跑通 `docker run hello-world`，理解镜像/容器/挂载/端口映射
- [ ] 用容器跑一个 Python 脚本（挂载本地目录方式）
- [ ] 写阶段总结笔记，推送到 GitHub
