# 阶段 1：深度学习 / NLP 基础（第 3-6 周，约 40h）

**目标**：建立面试八股的根基。不必深抠数学推导，但每个概念要能"讲人话+画图+说清为什么"。

## 任务清单

### 第 3 周：深度学习基础
- [ ] 李宏毅课程：神经网络基本概念（神经元/激活函数/损失函数）
- [ ] 梯度下降与反向传播的直觉理解
- [ ] 过拟合判断与缓解（Dropout / L1L2 正则 / 早停 / 数据增强）
- [ ] d2l 对应章节跑一个 MNIST 小例子（PyTorch）

### 第 4 周：序列模型与词向量
- [ ] CNN 概念（卷积/池化）——面试会顺带问
- [ ] RNN / LSTM 为什么难训练长序列（梯度消失/爆炸）
- [ ] Word2Vec 词向量思想（CBOW / Skip-gram 概念即可）
- [ ] 思考题：为什么 NLP 后来转向了 Transformer？

### 第 5 周：Transformer 精读 ★
- [ ] 3Blue1Brown Attention 视频建立直觉
- [ ] Self-Attention 公式：Attention(Q,K,V)=softmax(QK^T/√d_k)V，理解每一步
- [ ] 为什么要除以 √d_k？（点积过大→softmax 梯度消失）
- [ ] Multi-Head：不同子空间学不同关系
- [ ] 位置编码：为什么要有？正弦编码 / RoPE 了解
- [ ] Encoder-Decoder 整体结构、残差连接、LayerNorm、FFN
- [ ] 读一遍"图解 Transformer"（The Illustrated Transformer 中文版）

### 第 6 周：BERT vs GPT + 动手
- [ ] BERT：双向编码、Masked LM、适合理解类任务
- [ ] GPT：自回归生成、Next Token Prediction、适合生成
- [ ] 预训练 → SFT → RLHF 三阶段总览（阶段 2 会深入）
- [ ] **手写 scaled dot-product attention**（NumPy 或 PyTorch，对照 d2l 代码）
- [ ] 写一篇 Transformer 学习笔记博客，发布到 CSDN/知乎

## 自测题（对应 interview 题库第一、二部分）

1. 白板画出 Transformer 结构，标出 Q/K/V 流动路径
2. 为什么用 Multi-Head 而不是一个大的 Attention？
3. BERT 为什么不能直接做文本生成？
4. Transformer 训练时为什么要 mask？（因果 mask 防止偷看未来 token）
